SUMATRA'S WESTKUST SOCIETY — V4
====================================
V4 menambahkan konsep "Jejak Sumber":
- Cover image URL
- Tags
- Sumber primer/sekunder/dll dengan format baris
- Catatan Penulis
- Panel sumber pada halaman artikel
- Link sumber eksternal opsional

Format Jejak Sumber:
JENIS | JUDUL/DOKUMEN | DETAIL/HALAMAN | URL OPSIONAL

Contoh:
PRIMER | Contract VOC 1693 | ANRI DXLVI-546 |
SEKUNDER | Claudine Salmon | pembahasan Selden Map | https://...
